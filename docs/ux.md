# UX-концепция

## Персоны

### Персона 1: Сотрудник
- Цели: быстро найти свободную переговорную, забронировать её без конфликтов, не тратить время на ручную проверку расписания.
- Ожидания: понятный список комнат, удобные фильтры, быстрая форма бронирования, видимый результат после создания заявки.
- Важно в первые 30 секунд: увидеть доступные комнаты, фильтры по времени, вместимости и оборудованию, а также кнопку входа в систему.

### Персона 2: Офис-менеджер / администратор
- Цели: следить за загрузкой комнат, управлять данными о помещениях и проверять, что в комнатах есть нужное оборудование.
- Ожидания: понятная статистика, удобное редактирование данных, быстрый доступ к списку всех бронирований.
- Важно в первые 30 секунд: увидеть сводку по комнатам, статистику использования и раздел с управлением данными.

## User Stories

1. Как сотрудник, хочу войти в систему и увидеть доступные переговорные, чтобы сразу выбрать подходящую комнату.
   - Шаги: открыть приложение, пройти авторизацию, посмотреть список комнат, отфильтровать по нужным параметрам.
   - Done-критерий: пользователь видит только доступные ему комнаты и может начать бронирование.

2. Как сотрудник, хочу забронировать комнату на нужное время, чтобы не было пересечений с другими встречами.
   - Шаги: выбрать комнату, указать время и участников, проверить конфликт, сохранить бронирование.
   - Done-критерий: бронирование создаётся только если нет пересечения по времени.

3. Как офис-менеджер, хочу видеть статистику использования комнат, чтобы понимать, какие комнаты заняты чаще всего.
   - Шаги: открыть раздел статистики, посмотреть загрузку комнат, сравнить показатели по разным помещениям.
   - Done-критерий: на экране есть понятная сводка по загрузке и бронированиям.


## Приоритеты

- Первый экран: вход в систему, краткая навигация и список доступных переговорных с основными фильтрами.
- Вторично: подробная форма бронирования, редактирование и отмена встреч, статистика и данные по оборудованию.
- Сознательно убрано: лишние анимации, сложные декоративные блоки и перегруженная главная страница.

## Дизайн-система (Taiga UI 4)

- **Кастомные компоненты:** карточка переговорной, форма бронирования, список бронирований, блок статистики, экран входа, пустые состояния.
- **Визуальный стиль:** чистый рабочий интерфейс, минимум декоративных элементов, понятные индикаторы загрузки и ошибок.

## Карта экранов

### 1. Вход в систему
- **Элементы:** форма email/пароль, кнопка входа, ссылка на регистрацию.
- **После входа:** редирект на список комнат.

### 2. Регистрация
- **Элементы:** форма email, пароль, подтверждение, кнопка регистрации.
- **После регистрации:** редирект на экран входа.

### 3. Список переговорных
- **Элементы:** поле поиска, фильтры (время, вместимость, оборудование), сортировка, сетка карточек комнат, пагинация.
- **Взаимодействие:** клик на карточку → детали комнаты.

### 4. Детали комнаты
- **Элементы:** название, вместимость, описание, оборудование, расписание/календарь, кнопка "забронировать".
- **Взаимодействие:** кнопка "забронировать" → форма бронирования.

### 5. Создание бронирования
- **Элементы:** выбор комнаты, дата/время, количество участников, оборудование, кнопка "создать".
- **Валидация:** проверка конфликтов по времени и вместимостью.
- **После создания:** уведомление и редирект на "мои бронирования".

### 6. Редактирование бронирования
- **Элементы:** те же, что при создании, но предзаполненные.
- **После сохранения:** редирект на "мои бронирования".

### 7. Мои бронирования
- **Элементы:** таблица бронирований (название, дата, время, участники, статус), фильтры по статусу, действия (редактировать, отменить).
- **Взаимодействие:** кнопки редактирования и удаления.

### 8. Отмена бронирования
- **Элементы:** подтверждение "вы уверены?", информация о комнате и времени, кнопки отмены и удаления.
- **После подтверждения:** бронирование помечается как отменённое.

### 9. Статистика
- **Элементы:** таблица загрузки комнат, популярная комната, свободная комната, список ближайших бронирований.

### 10. Управление комнатами
- **Элементы:** таблица комнат (название, вместимость, локация, статус), кнопки добавить/редактировать/удалить, форма редактирования.

### 11. Ошибка 404
- **Элементы:** сообщение "404", кнопка "на главную".
