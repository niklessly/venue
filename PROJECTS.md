## 3. Система бронирования переговорных комнат

**Описание проекта (от бизнеса)**
Приложение для бронирования помещений в офисе с учётом вместимости и оборудования.

**Бизнесовые требования (верхнеуровневые)**

- Пользователь может просматривать список доступных комнат.
- Пользователь может бронировать комнату на конкретное время.
- Пользователь может указывать параметры встречи (количество участников, оборудование).
- Пользователь ожидает проверку на конфликты бронирований.
- Пользователь может отменять или переносить бронирование.
- Пользователь может создавать повторяющиеся бронирования.
- Пользователь ожидает уведомления о предстоящих встречах.
- Пользователь может просматривать статистику использования комнат.
- Пользователь может добавлять оборудование к комнатам (проектор, видеосвязь).
- Требуется авторизация и разделение данных между компаниями.
